# 预览

不连后端、不连集群，在本机把每个页面、每种状态都打开来看。

```bash
pnpm preview            # 开发模式：改了页面马上看到
pnpm preview --built    # 用构建好的那一份（先 pnpm build）
```

打开终端里打印的地址（`/__preview`）。那是目录页：有哪些情景，每个情景里有哪些页面，点一下就切过去。

要 Node 24。这台机器默认是 Node 25，先 `export PATH=$HOME/.nvm/versions/node/v24.21.0/bin:$PATH`。

## 它是怎么回事

```text
浏览器 ──> 前门（preview/server.mjs）
             ├─ /api/…      样例：从真的后端录下来的返回
             ├─ /__preview  目录页
             └─ 其余        Next（网页端原样的代码）
```

| 项             | 说明                                                               |
| -------------- | ------------------------------------------------------------------ |
| 网页端的代码   | 一行不改。它以为自己连的是真的后端                                 |
| 不进正式构建   | 预览是网页端之外的一个进程，镜像里没有它                           |
| 登录           | 替身。点「登录」就算登录了；目录页上可以切到没登录的样子           |
| 跨应用跳转     | 替身，规则和后端相同。别的应用的地址指向它们各自的预览             |
| 实时推送       | 把录下来的事件一帧一帧重放                                         |
| 改动类的请求   | 录过的按录下来的答；没录过的答 501 并说明，不装作成功              |
| 没有样例的请求 | 答 404，终端里打印一行，目录页最下面也列出来。做页面时照着它补样例 |

## 样例从哪来

样例不手写。由这个应用的后端在测试库里把各种状态造出来，把接口的真实返回录下来。
所以样例和真接口的形状一定一致；后端改了接口，重录一遍就跟上。

| 项   | 位置                                                                 |
| ---- | -------------------------------------------------------------------- |
| 样例 | `preview/fixtures/<情景>/`，一个情景一个目录，`manifest.json` 是目录 |
| 录制 | 各应用后端仓库里的录制脚本。模板没有业务接口，所以模板没有录制脚本   |

`manifest.json`：

| 项                           | 含义                                                     |
| ---------------------------- | -------------------------------------------------------- |
| `id`、`title`、`description` | 情景的名字与说明。`id` 要和目录名相同                    |
| `signed_in`                  | 这个情景是不是登录的。默认是                             |
| `user`                       | 登录的人叫什么                                           |
| `pages`                      | 这个情景里值得看的页面，目录页上列出来                   |
| `responses`                  | 每个接口的返回：方法、路径、参数、状态码、内容在哪个文件 |
| `streams`                    | 事件流：路径、事件在哪个文件                             |

## 预览说明不了什么

预览只能说明页面做得对不对。登录、权限、实时推送、沙箱、Codex、本地代理连起来能不能跑，要到集群上才验得到。
